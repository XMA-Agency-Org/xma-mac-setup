Getting Started

After the script finishes, you need to do two things:

1. Restart your terminal

Close Kitty and open it again. This loads all your new settings.

2. Log in to Claude

Type claude and press Enter. Follow the steps to connect your account.

What is a terminal? It's a text-based way to talk to your computer. Instead of clicking icons, you type short commands. It sounds scary but you only need to know a handful of them.

How to open Kitty

Press cmd+space, type Kitty, press Enter. That's it — your terminal is open.

Kitty Terminal

Kitty is your terminal app. It supports tabs and split screens so you can have multiple things open at once.

Tabs

cmd+tOpen a new tab (stays in same folder)
cmd+wClose current tab
cmd+]Switch to next tab
cmd+[Switch to previous tab

Split screen

Work in two places at the same time in the same window.

cmd+dSplit screen left and right
cmd+shift+dSplit screen top and bottom
cmd+enterOpen new window (same folder)

Other

cmd+=Make text bigger
cmd+-Make text smaller
cmd+0Reset text to default size
ctrl+cmd+fToggle fullscreen

Shell Tips

These keyboard shortcuts work anywhere in the terminal while you're typing.

Autosuggestions

As you type, a faded grey suggestion appears based on what you've typed before. It's like autocomplete on your phone.

ctrl+spaceAccept the suggestion
ctrl+eAccept and immediately run it
(keep typing)Ignore the suggestion

History

The terminal remembers every command you've typed.

↑ / ↓Go back and forward through previous commands
ctrl+rSearch through your entire history — just start typing

Tab completion

Press Tab while typing a file or folder name to get a visual picker. Use arrow keys to select, Enter to confirm.

Stuck? Press ctrl+c at any time to cancel whatever is happening and get back to a fresh prompt.

Navigating Folders

When you open the terminal, you start in your home folder. Use these commands to move around — like clicking through folders in Finder, but with text.

workGo to your Work folder
cd foldernameGo into a folder
..Go up one folder
...Go up two folders
lsList files in current folder
llList files with details (size, date)
ltShow files as a tree (including subfolders)
Pro tip: You don't have to type full folder names. Type the first few letters and press Tab — it will complete it automatically.

Reading files

cat filenameShow the contents of a file with colours
find filenameSearch for a file by name
grep "word" fileSearch for a word inside a file

Git — Saving Your Work

Git is like "track changes" in Google Docs — it saves snapshots of your work so you can go back in time, and share code with your team on GitHub.

gsSee what files you've changed
ga .Mark all changes as ready to save
ga filenameMark one specific file as ready to save
gc -m "message"Save a snapshot with a description of what you did
gpUpload your saved snapshots to GitHub
glDownload latest changes from GitHub
gdSee exactly what lines changed in your files
glogSee the full history of all saved snapshots

The basic workflow

Every time you finish a chunk of work:

# 1. Check what changed
gs

# 2. Mark everything ready
ga .

# 3. Save a snapshot with a message
gc -m "what I changed"

# 4. Upload to GitHub
gp

Claude AI

Claude is your AI assistant, available directly in the terminal.

ccOpen Claude chat (short version)
claudeSame — open Claude chat
claude /helpSee all available commands and skills

Generate images with AI

Type /gen followed by a description of what you want:

/gen a minimalist logo for a creative agency
/gen a sunset over mountains, cinematic
/gen a flat illustration of a laptop on a desk

The image is saved in your current folder.

Understanding Your Prompt

The line where you type shows useful information about where you are and what's happening with your code.

╭─ ~/Work/my-project on main (!+?)
╰─ ❯
~/Work/my-projectYou are inside this folder
mainYou are on the "main" git branch
!You have unsaved changes in your files
+You have changes ready to commit
?There are new files git doesn't know about yet
❯ (green)Last command worked — ready for input
❯ (red)Last command failed

Troubleshooting

command not found
The command is misspelled, or the tool isn't installed. Check your spelling and try again.
Nothing is happening / cursor is blinking but won't respond
The terminal is waiting for something or stuck. Press ctrl+c to cancel and get back to a normal prompt.
Permission denied
You need admin rights. Add sudo before your command and press Enter. It will ask for your Mac password.
Accidentally opened something strange (full screen text, colon at bottom)
You're in a viewer. Press q to quit and return to normal.
I closed the terminal and lost what I was doing
Your files are safe — they're saved on disk. Open Kitty again, navigate back to your folder with work or cd, and carry on.
Git says "nothing to commit"
You haven't made any changes since your last save. That's fine — run gs to see the current state.
